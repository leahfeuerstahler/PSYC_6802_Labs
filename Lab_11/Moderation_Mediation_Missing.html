Moderation

Moderation

To illustrate a moderation analysis, we will predict final exam scores from prior GPA, using attendance rate as a moderator. In other words, we want to know whether the linear regression of final exam scores on prior GPA changes across different attendance rates.

First, we want to mean-center the predictors, prior GPA and attendance rate. To center variables, subtract the mean from each score. It is usually convenient to add centered variables to the dataset:

mean(dat$priGPA)
[1] 2.586775
mean(dat$attend)
[1] 26.14706
dat <- dat %>% mutate(priGPA_C = priGPA - mean(priGPA),
                      attend_C = attend - mean(attend))

Moderation

modrmod <- lm(final ~ priGPA_C * attend_C, dat)

Exactly as we did for 2-Way ANOVA, we now need to evaluate the main effects at different values of the moderator!

To probe the moderation effect, we can plug in different values of the moderator.

Some options:

  • mean of moderator
  • one standard deviation above/below the mean of the moderator
  • specific meaningful values

Mediation

Mediation: Single Mediator Model

Path diagram for the single mediator model:

                     ----------
                    |Mediator m|
              a  /   ----------  \ b
                /                 \
       -----------        c'       ---------
      |Predictor x| ------------> |Outcome y|
       -----------                  ---------

For illustration, we will model final exam scores as the outcome (\(y\)), with ACT scores as the predictor (\(x\)), and termgpa as a potential mediator (\(m\)).

Mediation

The first thing we need to do is fit two regression models:

  1. Mediator m ~ predictor x

  2. Outcome y ~ predictor x + mediator m

mod_m <- lm(termgpa ~ ACT, dat) # path a
mod_y <- lm(final ~ ACT + termgpa, dat) # paths b and c'

Mediation: Bootstrapping

For the bootstrapping, we feed the mod_m and mod_y objects to the mediate function from the mediation package. Because this method requires random sampling (here, 1,000 bootstrap samples), it takes a few seconds to run.

set.seed(1423)
med_mod <- mediate(model.m = mod_m, 
                   model.y = mod_y,
                   treat = "ACT", 
                   mediator = "termgpa", 
                   boot = TRUE, sims = 1000)

Mediation: Bootstrapping

The estimated mediation effect \(\hat{a}\times \hat{b}\) is .149 (ACME), and is significantly different from zero, 95% CI = [.097, .204]. Your results may differ if you use a different seed.

Mediation: Bootstrapping

The lavaan package provides another way to fit a mediation model that makes it easier to handle missing data

  • First, we use lavaan-specific syntax to fit the model

  • final, termgpa, and ACT are columns in the data set

  • a, b, and c are user-provided labels for regression coefficients

  • ~ indicates regression, := indicates a calculated combination of parameters

medmod <- "
final ~ b * termgpa + c * ACT
termgpa ~ a * ACT

ind := a*b    # calculate the indirect effect
tot := a*b+c  # calculate the direct effect
"

Mediation: Bootstrapping

We can fit this model using the sem function from lavaan

  • se = "boot" means to calculate bootstrapped standard errors

  • bootstrap indicates the number of bootstrap replications

lav_res <- sem(medmod, data = dat, se = "boot", bootstrap = 1000)
summary(lav_res, header = FALSE)

Appendix: Missing Data Handling

Missing Data Handling

In lecture, we learned about multiple imputation and maximum likelihood as methods to account for missing data.

  • In our dataset, there are 6 missing values of hwrte.

  • In the following slides, we will illustrate these methods for the following regression:

termgpa ~ priGPA + hwrte

Maximum Likelihood with lavaan

The lavaan package requires specifying the model as a character string first:

gpa_mod <- "termgpa ~ priGPA + hwrte"

Then, we fit the model with the sem function. Some options we may want to use with missing data:

  • std.ov = TRUE means to standardize variables - this can help estimation work correctly and avoid errors

  • missing = "FIML" uses Full Information Maximum Likelihood to estimate parameters from all available data

  • fixed.x = FALSE ensures proper missing data handling if there is missing data in the predictors

  • estimator = "MLR" uses maximum likelihood estimation with robust standard errors, which is preferable when data are not normally distributed

Maximum Likelihood with lavaan

gpa_lavaan <- sem(gpa_mod, data = dat, std.ov = TRUE,
                  missing = "FIML", fixed.x = FALSE,
                  estimator = "MLR")
