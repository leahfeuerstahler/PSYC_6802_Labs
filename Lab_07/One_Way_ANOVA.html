We will recode our IV genre as a factor variable rather than as a character variable. More broadly, this recoding is very important, especially when your IV is coded as a numeric variable. If you specify the IV as numeric, most ANOVA functions will give you output, but it will be incorrect. Specifically, these functions will treat group codes as a continuous variable rather than as a grouping variable.

dat <- dat %>% mutate(genre = factor(genre))

aov Approach

aov is R’s built-in command for running ANOVAs. aov is also the class of object outputted by a function call to aov(). This approach assumes homoskedasticity, which we’ll address later.

aov_res <- aov(tomatoMeter ~ genre, dat)
summary(aov_res)
              Df  Sum Sq Mean Sq F value Pr(>F)

Residuals   1907 1276564     669

The emmeans Package

In lecture we showed some “built-in” functions for multiple comparisons. Here we’ll look into another option: the emmeans package.

  • First you need to create a new object using the emmeans() function. The main arguments of this function are you aov object and your IV(s), which you specify after the specs = argument.
library(emmeans)
em <- emmeans(aov_res, specs = "genre")

Then, you can apply many of the emmeans package functions to the newly created object to compute all sorts of pairwise comparisons and contrasts.

Cohen’s \(d\) with emmeans

We can calculate the Cohen’s \(d\) between every group pairs. If you remember the formula is \(d_{i,j} = \frac{M_{i} - M_j}{\sqrt{MSW}}\). The eff_size() function does this for all our groups.

  • eff_size() requires the em object, the standard error \(\sqrt{MSW}\), and the residual degrees of freedom \(df_{\mathrm{within}}\)
eff_size(em, 
         
         # sigma(aov_res) equals sqrt(MSW)
         sigma = sigma(aov_res), 
         
         # df.residual(aov_res) extracts the df within from the model
         edf = df.residual(aov_res))

Pairwise Comparisons (post-hoc): Tukey’s HSD

The pairs() function will run pairwise comparisons if you enter the em object. You also need to specify the type of adjustment through the adjust = argument.

  • For example, Tukey’s HSD:
pairs(em, adjust = "tukey")
 contrast          estimate   SE   df t.ratio p.value
 Comedy - Drama      -13.13 1.25 1907 -10.497  <.0001
 Comedy - (Sci-fi)    -6.69 2.04 1907  -3.279  0.0030
 Drama - (Sci-fi)      6.44 2.03 1907   3.171  0.0044

P value adjustment: tukey method for comparing a family of 3 estimates

Here we see that dramas are rated significantly higher than both comedies and sci-fi movies, and that sci-fi is rated significantly higher than comedy

Post-Hoc Tests with aov

There are many types of adjustments, and the adjust = argument allows for several:

  • "tukey": this will perform Tukey’s HSD.
  • "holm": pairwise \(t\)-tests with Holm-adjusted \(p\)-values.
  • "bonferroni: pairwise \(t\)-tests with Bonferroni-adjusted \(p\)-values.
  • "Dunnett": an option that doesn’t assume homogeneity.
  • "none": no correction.

You can try substituting these into the adjust = argument from the previous slide; the only thing that will change is the p-value.

Contrasts

To check contrasts, we can use the contrast() function on the object. We can then specify contrasts using method =. Note that we must specify the contrasts as a list.

We also need to make sure we reference the correct order of our factor levels. We can check this as follows

levels(dat$genre)
[1] "Comedy" "Drama"  "Sci-fi"

So what will my contrasts look like if I want to test the hypothesis:

  • Drama vs. Comedy/SciFi (combined)

Contrasts

contrast(em, method = list(genre = c(-1, 2, -1)))
 contrast estimate   SE   df t.ratio p.value
 genre        19.6 2.69 1907   7.283  <.0001

Here, we reject \(H_0\) for both cases, so we find that dramas are rated significantly differently than sci-fi and comedy movies.

Weighted Least Squares with aov

First, we need to compute weights for WLS estimation. Weights are the inverse of the group-level variances (\(W_{\mathrm{group}} = \frac{1}{S^2_{\mathrm{group}}}\)).

dat <- dat %>% group_by(genre) %>%
  mutate(weights = 1 / var(tomatoMeter))

Next, we add these weights to our aov() call.

summary(aov(tomatoMeter ~ genre, dat, weights = weights))
              Df Sum Sq Mean Sq F value Pr(>F)    
genre          2  110.5   55.26   55.26 <2e-16 ***
Residuals   1907 1907.0    1.00                   
---

Alternative ANOVA Functions and Robust Methods

Other Packages for ANOVA

The default R methods don’t include all of the robust estimation methods and post-hoc comparisons that we might want to use. Other packages have been developed to make these methods more easily available and more user-friendly. We’ll learn about two ANOVA commands in new packages today: ez from ezANOVA and welch_anova_test from rstatix.

ezANOVA makes it easy to specify more complicated models, and it will be the main function we use for more complex ANOVA models. Another advantage of ezANOVA is that there is an option to return an aov class object, so all of the functions above that used aov() objects can also use ezANOVA output.

ANOVA with ezANOVA

ezANOVA(data = dat, dv = tomatoMeter, wid = id, between = genre)

Input:

  • data: dataset (other inputs are column names from this dataset)
  • dv: dependent variable
  • wid: within-subjects ID (person identifier variable - required)
  • between: between-subjects factor (grouping variable in one-way ANOVA)

Output:

  • Rather than the full ANOVA table, ezANOVA only gives the numerator and denominator \(df\), \(F\) statistic, \(p\) value, and ges = eta-squared effect size (\(\eta^2\))
  • ezANOVA also returns Levene’s test for homogeneity of variance. If this test is rejected, you have evidence against homogeneity, and you definitely want to use Welch’s test, WLS or White’s adjustment.

ezANOVA tends to give a lot of warnings, many of which can be ignored.

  • ezANOVA will automatically convert your subject identifier variable to a factor (if it not already a factor). This is usually appropriate, so the warning can be ignored.

  • ezANOVA will also warn if you don’t have equal group sizes. For the one-way ANOVA, you don’t need to worry about this (changing the type argument won’t change your output). This will matter when we have more than one IV.

ANOVA with ezANOVA

Welch’s test

Welch’s correction is available in the rstatix package. Functions in this package will not run with grouped data (we used the group_by function earlier), so we ungroup the data first.

dat <- dat %>% ungroup

Kruskal-Wallis Rank Sum Test

Finally, if we wish to avoid assumptions of normality, we can run the Kruskal-Wallis rank sum test, which also rejects the null hypothesis.

kruskal.test(tomatoMeter ~ genre, dat)

    Kruskal-Wallis rank sum test

data:  tomatoMeter by genre
Kruskal-Wallis chi-squared = 102.23, df = 2, p-value < 2.2e-16

To follow up with multiple comparisons, we might use pairwise tests that make the same assumptions, such as the pairwise Wilcoxon rank sum test:

pairwise.wilcox.test(x = dat$tomatoMeter, g = dat$genre, p.adjust.method = "holm")
