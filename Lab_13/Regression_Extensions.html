Overview

Functions for logistic regression:

  • glm(DV ~ IV1 + IV2 + ..., dat, family = binomial): fit the logistic regression model
  • coef(glm()) or summary(glm())$coefficients: extract coefficients for a glm model
  • fitted(glm()): get fitted values (predicted probabilities)
  • predict(glm(), newdata = ..., type = "response"): get predicted probabilities for new data scored with the fitted model
  • anova(glm1, test = "LRT"): likelihood ratio test comparing glm1 to the null model
  • anova(glm1, glm2, test = "LRT"): likelihood ratio test comparing glm1 to glm2 (where one model is a subset of the other model)

Function for multilevel regression:

  • lmer(DV ~ CV + (1 | ID), dat)

    • dat: dataset in long format

    • DV: column name of dependent variable

    • ID: column name of user IDs or other cluster variable

    • CV: column name of covariate (may be IV)

Logistic Regression

Let’s next fit a logistic regression model with Extraversion as a predictor.

The command to fit logistic regression is glm(). The formula notation is the same as for linear regression, but we need to add the argument family = binomial to tell R that we want logistic regression instead of another GLM.

glm1 <- glm(volunteer ~ extraversion, Cowles, 
            family = binomial)

Logistic Regression

round(summary(glm1)$coefficients, 3)
             Estimate Std. Error z value Pr(>|z|)
(Intercept)    -1.139      0.185  -6.146        0
extraversion    0.066      0.014   4.640        0

These results imply the following fitted equation:

\(\hat{P}(volunteer) = \frac{1}{1+\exp(-(-1.14 + .07Extraversion))}\)

  • -1.14 is the logit when Extraversion = 0 (highly introverted): \(P = \frac{1}{1 + \exp(1.14)} = .24\)

  • .07 is the increase in logit (predicted log odds of volunteering) for a one-point increase in Extraversion score

Coefficient interpretations

  • .07 is the increase in logit (predicted log odds of volunteering) for a one-point increase in Extraversion score

Or

exp(.07)
[1] 1.072508
  • For a one unit increase in Extraversion, volunteering becomes \(exp(0.07) = 1.07\) times as likely.

Sometimes \(exp(0.07) = 1.07\) might also be written as \(e^{0.07} = 1.07\)

Classification Accuracy

To evaluate accuracy, we need to get the fitted values for the training data.

fitted1 <- fitted(glm1)

Then, we classify subjects as being predicted to volunteer or not based on a .5 cutoff.

class1 <- ifelse(fitted1 > .5, "pred_yes", "pred_no")
table(class1, Cowles$volunteer)
          
class1      no yes
  pred_no  765 526
  pred_yes  59  71
(765 + 71)/(765 + 526 + 59 + 71)
[1] 0.5883181

We get around 59% accuracy which is not great. Extraversion may not be very informative in relation to the outcome.

Model Comparison

To test whether extraversion has “predictive power” associated with it, we conduct a likelihood ratio test comparing glm1 to the null model (a model with only an intercept).

anova(glm1, test = "LRT")

Here, we reject the null hypothesis that the null model fits as well as the model with extraversion. Therefore, we retain the model with extraversion as a predictor: \(\chi^2(dif, 1) = 22.022, p < .001\).

Wide vs. Long Data

Long data has as many rows, as few columns as possible

  • Multiple rows for one subject
  • One column for the DV
  • One column for each IV

Wide data has fewer rows, more columns

  • e.g., One row per subject
  • Multiple columns for the DV at different IV levels

Long data is usually preferred for data analysis

  • Some exceptions, such as for certain types of plots

Wide vs. Long Data

In this class, we have already seen some examples of moving between wide and long data.

tidyverse functions:

  • pivot_longer: move from wide format to long format
  • pivot_wider: move from long format to wide format

The Stroop data are stored in wide format. To change to long format:

dat_long <- dat %>% pivot_longer(cols = -Subject,
                                 names_to = "Contingency", 
                                 values_to = "PropError")

The cols = -Subject argument means to exclude the Subject column in the information that is shifted to the new columns. Instead, the Subject variable will be stretched in the long format. See next slide for the structure of dat_long.

Fitting multilevel models with lmer

To fit linear random-effects models, we can use the lmer function in the lme4 package.

mod <- lmer(PropError ~ (1 | Subject), dat_long)

This syntax means that PropError is the DV, Subject is the random effect (the mean for each subject is a random variable), and dat_long is the dataset.

For now, this model doesn’t account for the effect of Contingency level . It only models individual differences in the proportion of errors made.
